# Fictional Student Dataset

A small Python script that generates a fake dataset of 20 students.

## Columns
- Student_ID
- Department
- Level
- Attendance_Percentage
- Average_Exam_Score

## How to run
```
python generate_dataset.py
```
This creates `students.csv` in the same folder.
